# `@minikb/ui`

**Direction 02** React component kit — incubating in [minikb](https://github.com/liuyidi/minikb) (`packages/ui`).

Light-only canvas, near-black ink, `--mini-*` brand tokens bridged to shadcn-style semantic CSS variables. Consumed by `web/` via `"@minikb/ui": "file:../packages/ui"`.

## Quick start

```bash
cd packages/ui
npm install
npm run storybook   # http://127.0.0.1:6006
```

```tsx
import { Button } from "@minikb/ui/components/ui/button";
import "@minikb/ui/styles/mini-brand.tokens.css";
import "@minikb/ui/styles/bridge.css";
```

## Conventions

- **Stack:** React 19, Tailwind 4, `@base-ui/react`, `class-variance-authority`, Lucide icons
- **Sizing:** Form controls default to `h-11`; compact tier (`sm`) is `h-8` — trigger and dropdown rows stay aligned
- **Pickers:** `DatePicker` / `TimePicker` / `DateTimePicker` / `RangeDatePicker` — Ant Design–aligned panels; see individual Docs
- **Tests:** `npm run test` in `packages/ui` (Vitest)
